# Waste Expo invite — HTML email

Simple campaign email for WasteVantage at Waste Expo Australia (28–29 October 2026, Stand D161).

## Files

- `waste-expo-invite.html` — open this in a browser. Logo is embedded, so it works as a single file.
- `waste-expo-invite-esp.html` — use this in Mailchimp / Klaviyo / Outlook campaigns. Upload `wastevantage-logo.png` in the same folder or swap the image URL for your hosted logo.
- `wastevantage-logo.png` — logo for ESP upload

## How to send

1. Open `waste-expo-invite.html` to preview.
2. In your email tool, paste the HTML or import `waste-expo-invite-esp.html`.
3. If the logo does not show in the campaign tool, upload `wastevantage-logo.png` and keep the image path as `wastevantage-logo.png`.
4. Replies go back to your sending address (that is how people book 30 minutes with Andrew).
